# CMHoCFPTPGraphicGenerator
This is a simple version of the FPTPGraphic Generator. It is designed in order to quickly create graphics for By-Election as well as FPTP elections where MMP rules need not apply.
Below is an example of the graphics created for this purpose. 
A username.jpg inside the main folder is substituted in for the player photo within the graphics
